### 关于这个站点

用 [Jekyll](https://jekyllrb.com/) 配合 [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) 主题搭建,内容以 Markdown 书写,托管在 GitHub Pages 上,由 GitHub Actions 自动构建部署。

- **快** —— 纯静态文件,没有数据库查询
- **简单** —— 一个 Markdown 文件就是一篇文章
- **可版本控制** —— 每一篇文章都在 Git 里
